# Taste
- Prefers code audit/review deliverables structured as: (1) Executive Summary with a high-level health assessment and top critical risks, (2) Detailed Findings categorized by area (architecture, code quality, security, performance, testing), and (3) Actionable Recommendations as a prioritized roadmap (High/Medium/Low). Confidence: 0.9
- Expects audit findings to reference specific files/modules (with line numbers where possible) and to be rigorous and evidence-based, not hand-wavy generalizations. Confidence: 0.7
- Communicates in French (task requests are written in French, and French responses are left unremarked) even when prior context was English. Confidence: 0.8
- Prefers broad delegation with comprehensive execution: when told to "apply all the recommendations" or to "answer the pending questions in the project's interest", expects the full scope implemented — including resolving previously-deferred decisions (real benchmarks measured, crate license aligned and changed) with concrete actions rather than leaving them open; explicitly demanded the deferred LLM-engine integration be implemented and actually wired ("ça doit être branché"), not left as a detection-only sketch. Confidence: 0.9
- Values product DX that minimizes manual setup: asks whether the installer can self-install automatically, detect the AI agent (Claude Code, etc.), the LLM engine (Ollama/vLLM/llama.cpp), and the hardware environment, and auto-register the MCP server to simplify the user's work. Confidence: 0.7
- Expects git delivery to be completed as part of "done": explicitly asks whether the work has been committed and a PR created ("tu as commit et creer la PR ?") — a task is not finished while changes sit uncommitted in the working tree. Confidence: 0.7
- When a force-push is refused and the remote ref is missing, verifies the actual PR/remote state before pushing anything: discovers the PR was already merged upstream, confirms the work is present in master (checking key artifacts like the module split and installer scripts), and then aligns the local branch with master and deletes the now-orphaned local merge instead of force-pushing a redundant commit. Confidence: 0.6
